# PAUZE® — Digital Studio Website

A responsive, project-first portfolio for Pauze. Built with plain HTML, CSS, and JavaScript; no build step or package installation required.

## Included
- Monochrome editorial design with acid-green accents
- Responsive mobile navigation
- Project cards for PauzeWeather, PauzeControl, and other experiments
- About, technology stack, music, and contact sections
- CSS-generated radar and interface visuals
- Reduced-motion support

## Preview locally
Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8000
```

Visit `http://localhost:8000`.

## Customize
Update project links, the music destination, and contact email in `index.html`. Colors and responsive layout are in `styles.css`.
